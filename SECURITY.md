# Security policy

## Reporting a vulnerability

Report security problems privately through
[GitHub private vulnerability reporting](https://github.com/Exxeon/function-aws-lookup/security/advisories/new).
Don't open a public issue.

The maintainers listed in [OWNERS.md](OWNERS.md) aim to acknowledge a report
within five working days, and will agree a disclosure date with you once a fix
is available.

## Supported versions

Only the latest release receives security fixes.
